# Low-Level Programming (C)

**C from pointers to hash tables: memory, recursion, linked lists, file I/O and variadic functions.**

Holberton School × Tuwaiq Academy, Advanced Software Engineering track. Each folder is one project with numbered tasks.

| Folder | What it covers |
|---|---|
| `pointers_arrays_strings` | Pointers, arrays and string functions |
| `recursion` | Recursive functions |
| `argc_argv` | Command-line arguments |
| `malloc_free` · `more_malloc_free` | Dynamic memory |
| `structures_typedef` | Structs and typedef |
| `function_pointers` | Function pointers |
| `variadic_functions` | Functions with a variable number of arguments |
| `singly_linked_lists` · `doubly_linked_lists` | Linked lists |
| `file_io` | Reading and writing files with system calls |
| `hash_tables` | A hash table from scratch |

Compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89` · Betty style · Ubuntu
